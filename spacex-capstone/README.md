# SpaceX Falcon 9 First Stage Landing Prediction — IBM Data Science Capstone

**Author:** Jhoselyn Vera

Predicting whether the Falcon 9 first stage will land successfully, to estimate the cost of a launch (SpaceX: ~US$62M vs. >US$165M for other providers, thanks to first-stage reuse).

| 2 | Data collection — Web scraping (Wikipedia) | [jupyter-labs-webscraping.ipynb](jupyter-labs-webscraping.ipynb) |
| 3 | Data wrangling | [labs-jupyter-spacex-Data wrangling.ipynb](labs-jupyter-spacex-Data%20wrangling.ipynb) |
| 4 | EDA with SQL | [jupyter-labs-eda-sql-coursera_sqllite.ipynb](jupyter-labs-eda-sql-coursera_sqllite.ipynb) |
| 5 | EDA with data visualization | [edadataviz.ipynb](edadataviz.ipynb) |
| 6 | Interactive map with Folium | [lab_jupyter_launch_site_location.ipynb](lab_jupyter_launch_site_location.ipynb) |
| 7 | Interactive dashboard with Plotly Dash | [spacex_dash_app.py](spacex_dash_app.py) |
| 8 | Predictive analysis (classification) | [SpaceX_Machine_Learning_Prediction_Part_5.ipynb](SpaceX_Machine_Learning_Prediction_Part_5.ipynb) |

**Tools:** Python, pandas, NumPy, requests/fetch, BeautifulSoup, SQLite, matplotlib, seaborn, Folium, Plotly Dash, scikit-learn.
